
# Tetris 8086

A retro-inspired Tetris game written in 8086 Assembly, running in dosbox.

## Demo

![Tetris Gameplay](Assets/tetris-demo.gif)

## About

This project is an implementation of Tetris written in x8086 Assembly
for DOS, using TASM and dosbox.

The goal was to build a complete playable game while working close
to the hardware, handling graphics, game logic, input, and rendering
at a low level.

## Features

- Classic Tetris gameplay
- Piece movement and rotation
- Collision detection
- Line clearing and scoring
- Next-piece preview
- Custom graphics and color palette

## Built With

- 8086 Assembly

## Running the Game

### Requirements

- dosbox or dosbox
- tasm and tlink

### Instructions

1. Clone this repository.
2. Open dosbox.
3. run the make command and it should run the game.
